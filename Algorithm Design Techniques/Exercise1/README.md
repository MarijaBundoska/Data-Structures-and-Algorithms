## Exercise 1 - Constructing the Largest Possible Number from Given Digits

We are given **N digits**. Write an algorithm that constructs the largest possible number using those digits.

**Input:** The first number in the input is the number of digits N, followed by the given digits in the next line.

**Output:** Print the largest possible number that can be constructed using the given digits.

---

## Задача 1 - Формирање на најголемиот можен број од дадени цифри

Дадени се **N цифри**. Да се напише алгоритам кој ќе го даде најголемиот можен број составен од тие цифри.

**Влез:** Првиот број од влезот е бројот на цифри N, а потоа во следниот ред се дадени цифрите.

**Излез:** Најголемиот број кој може да се состави од тие цифри.
