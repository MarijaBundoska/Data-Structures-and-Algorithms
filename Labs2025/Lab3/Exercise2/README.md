## Exercise 2 - Finding the Smallest Number with N Digits and a Given Digit Sum

Given a digit sum `M` and a number of digits `N`, find the smallest number with `N` digits whose digits add up to `M`.

**Input:**

The input contains two integers: `N`, the number of digits, and `M`, the required sum of digits.

**Output:**

Print the smallest number with `N` digits whose digits add up to `M`. If no such number exists, print `"Ne postoi"`.

**Example:**

**Input:**
```text
2 10
```

**Output:**
```text
19
```


## Задача 2 - Наоѓање на најмалиот број со N цифри и дадена сума на цифри

За дадена сума `M` на цифри и број на цифри `N`, да се најде најмалиот број со `N` цифри чии цифри ја формираат дадената сума.

**Влез:**

На влез се дадени два броја: `N` — бројот на цифри и `M` — сумата на цифрите.

**Излез:**

На излез треба да се испечати најмалиот број со `N` цифри кој ја формира дадената сума. Ако не постои таков број, на излез да се испечати `"Ne postoi"`.

**Пример:**

**Влез:**
```text
2 10
```

**Излез:**
```text
19
```
